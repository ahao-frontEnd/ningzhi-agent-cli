# Ningzhi

A personal AI Agent like OpenClaw, including tools, skills, memory, hook, sub-agent, MCP sever, etc. Run in the terminal.

## tech

- runtime: nodejs
- language: typescript
- package tool: pnpm
- agent framework: langGraph
- LLM API: moonshot kimi
- CLI tool: commander.js

## command

```bash
pnpm dev
pnpm test
pnpm build
```
